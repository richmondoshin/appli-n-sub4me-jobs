# Appli.n.Sub4me job index

A daily list of current UK product and UX design job postings, taken from the public job feeds of the companies in
`skill/job-agent/data/companies.json`. Built by Richmond Oshin for Appli.n.Sub4me.

- **The list:** [`design-uk.json`](design-uk.json), updated every day by GitHub Actions
  (`.github/workflows/daily-index.yml`).
- **Read it from:** `https://raw.githubusercontent.com/richmondoshin/appli-n-sub4me-jobs/main/design-uk.json`
- **What's in it:** only public job postings (company, title, location, link to the employer's own job page, date,
  description). No CVs, no personal data.
- Each job links to the employer's own page. Apply there.
